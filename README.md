How to Deploy on GitHub Pages (Free)
1. Create a new repository
Go to github.com/new
Repository name example: `portfolio` or `academic-portfolio`
Set visibility to Public
Do not initialize with README (this repo already has one)
Click Create repository
2. Upload / push these files
Option A — Upload via browser
On the new repo page, click uploading an existing file
Drag `index.html` and `README.md` into the area
Commit
Option B — Using Git (recommended)
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
# copy index.html and README.md into this folder
git add .
git commit -m "Add academic portfolio website"
git branch -M main
git push -u origin main
```
3. Enable GitHub Pages
Open the repository → Settings → Pages
Under Source, select Deploy from a branch
Branch: `main` · Folder: `/ (root)`
Click Save
Wait 1–2 minutes, then open:  
`https://<your-username>.github.io/<repo-name>/`
